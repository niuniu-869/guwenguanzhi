## 任务

为《古文观止》的下列文章生成元数据。

**标题**：{title}
**作者**：{author}（{dynasty}）
**出处**：{source}

**全文**：
{text}

---

## 要求

### background（写作背景，200-300字）

交代：
1. 时代背景（年代、政治/社会环境）
2. 作者处境（写作时的具体境遇）
3. 写作动机（针对何人何事）

**禁止**：套话（如"具有重要意义"）、未经考证的细节。

### appreciation（文学赏析，300-500字）

分析：
1. 文体与结构（叙事/议论/抒情、篇章布局）
2. 艺术特色（修辞、语言、节奏）
3. 思想内涵（核心观点、价值立场）
4. 文学史地位（可选，若有经典性再谈）

**禁止**："千古名篇""脍炙人口"之类空话。

### tags（3-5 个标签）

从以下类别中选择或自拟：
- 文体：叙事 / 议论 / 抒情 / 山水 / 赋 / 骈文 / 书信 / 序跋 / 碑铭 / 策论 / 奏疏 / 祭文 / 寓言
- 主题：政治 / 军事 / 人物 / 哲理 / 友情 / 怀古

### author_bio（作者简介，100-200字）

包含：字号、生卒年（或活动年代）、籍贯、主要官职、代表作、文学史地位。

若作者已在前面出现过（本次不是其首篇），可简化为"已见前篇《XX》作者简介"，但若是系列中首篇，必须完整给出。

## 输出格式

```json
{
  "background": "...",
  "appreciation": "...",
  "tags": ["标签1", "标签2", "标签3"],
  "author_bio": "...",
  "characters": [
    {
      "id": "稳定 ID",
      "name": "人物主称",
      "aliases": ["别称"],
      "role": "朝代 + 身份 + 本文角色",
      "stance": "立场/处事方式",
      "motive": "核心动机",
      "relations": [
        {"target": "另一人物 name", "type": "关系类型", "note": "可选说明"}
      ]
    }
  ]
}
```

若全文无可考实名人物（纯山水/抒情篇），`characters` 输出 `[]`。
