## 人物卡抽取规则（characters）

用于在元数据阶段抽取本文涉及的**关键人物**及其关系、立场、动机，帮助读者建立理解骨架。

### C1 · 何时输出 `characters`

**收录对象（三类都要）**：
1. **有名有姓的历史人物**：作为本文叙事/议论主体的实名人物
2. **有叙事功能的无名角色**：如"武陵渔人""客""童子""翁""妪"——只要**有独立行动或对话**且是**情节推动者**，必须收录
3. **作者本人**：若作者以第一人称参与叙事（《赤壁赋》苏子、《石钟山记》苏轼亲访等）

**不收录对象**：
- 仅作用典/引证且非叙事主体（如议论文中引"尧舜""桀纣"做道德参照）
- 神话传说角色作为泛指（如"黄泉""冥司"）
- 仅出现在赏析背景中而不在本文正文的人物

**空数组场景**：全文为纯写景/抒情/咏物，**无任何独立行动的角色**（如《醉翁亭记》虽有"太守"出现但基本只作抒情自称，若判断其为作者抒情视角可纳入作者，否则可空；《兰亭集序》纯抒情可空）

**数量**：通常 2-6 人，至多 8 人。只有 1 个也要输出（如独白抒情+作者）。

### C1.1 · 无名叙事角色的 `id` / `name` 约定

若角色无专名：
- `id` 用描述性英文（如 `wuling_fisherman` / `the_guest` / `the_child`）
- `name` 用文中的称呼原文（"武陵渔人"/"客"/"童子"）
- `aliases` 留空数组 `[]`
- `role` 写"本文中的无名叙事角色 + 身份描述"

示例（《前赤壁赋》）：

```json
{
  "id": "the_guest",
  "name": "客",
  "aliases": [],
  "role": "本文中与苏子同舟夜游的友人（无名），借乐曲起兴发抒人生短促之叹",
  "stance": "由眼前赤壁引发对曹操功业与人生无常的哀叹，悲观低沉",
  "motive": "借水月之景抒发个人生命有限、功名易逝的怅惘，引出苏子以哲理开解",
  "relations": [
    {"target": "苏轼", "type": "朋友", "note": "同舟夜游，借问答推动全文哲思"}
  ]
}
```

### C2 · 字段定义

```json
{
  "id": "字母/下划线组成的稳定 ID，如 zheng_zhuang_gong",
  "name": "主称（中文原名）",
  "aliases": ["字/号/谥号/小名/别称"],
  "role": "朝代 + 身份 + 本文角色（一句话）",
  "stance": "立场/性格/处事方式（一句话，具体不抽象）",
  "motive": "在本文事件中的核心动机（一句话）",
  "relations": [
    {"target": "另一人物 name", "type": "关系类型", "note": "具体说明（可选）"}
  ]
}
```

### C3 · 关系类型枚举

`relations[].type` 必须取自下列枚举：

```
父子 母子 兄弟 夫妻 君臣 师生 朋友 同僚 对手 盟友 亲属 门客 下属 上司
```

复合关系选最主导的一个（如"既为君臣又为对手"选 `对手`，在 `note` 里补充"名义君臣"）。

### C4 · 写作要求

- **客观、具象、不议论**。`stance` 不要写"狡猾""仁义"这类空泛评语，写"隐忍以待时机、以礼掩兵"这类具象行为
- **紧扣本文**。动机只写本文情节内的动机，不涉及此人全传
- **避免复述白话翻译**。人物卡是聚合视图，不是段译重排

### C5 · 禁止事项

- 禁止将神话传说人物（黄帝、尧舜）、仅作论据的历史人物纳入
- 禁止输出 `role` / `stance` / `motive` 为空字符串的卡片
- 禁止 `relations.target` 指向 `characters` 数组中不存在的人物

### C6 · 示例（《郑伯克段于鄢》）

```json
[
  {
    "id": "zheng_zhuang_gong",
    "name": "郑庄公",
    "aliases": ["寤生"],
    "role": "春秋初期郑国国君，本文主角",
    "stance": "表面容让以守孝道名声，实则以礼制为度纵弟自毙",
    "motive": "在不违背宗法孝道的前提下铲除共叔段对君权的威胁",
    "relations": [
      {"target": "武姜", "type": "母子", "note": "幼年被母厌恶，后曾立誓不及黄泉不相见"},
      {"target": "共叔段", "type": "兄弟", "note": "政治对立面，最终出兵讨伐"},
      {"target": "祭仲", "type": "君臣", "note": "臣下多次进谏，庄公以待时之计回应"}
    ]
  }
]
```
