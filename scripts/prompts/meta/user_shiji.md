## 任务

为《史记》下列卷目生成元数据。

**卷号**：卷{juan}
**标题**：{title}
**体例**：{category_name}
**作者**：司马迁（约前145 - 约前86）
**原文**（可能节选）：
{text}

---

## 要求

### summary（内容提要，150-250字）

概括：
1. 主要人物（按在本卷中的重要性排序）
2. 主要事件（按时间顺序）
3. 时代背景（该卷所涉历史时期）

### appreciation（文学与史学价值评析，250-400字）

分析：
1. 叙事技法（如本纪的编年叙述、列传的人物刻画、世家的家族脉络）
2. 思想立场（司马迁对人物/事件的褒贬）
3. 名句或经典片段
4. 在《史记》整体结构中的位置

### tags（3-5 个标签）

从类别中选择：
- 体例：本纪 / 世家 / 列传 / 表 / 书
- 主题：政治 / 军事 / 外交 / 经济 / 文化 / 哲学 / 人物
- 时代：先秦 / 秦末 / 楚汉 / 西汉

### key_figures（本卷主要人物数组）

列出本卷重点人物，3-7 人。

### historical_period（历史时期）

如："春秋末至战国中期"、"楚汉相争（前206-前202）"、"西汉景帝至武帝初"。

---

## 输出格式

```json
{
  "summary": "...",
  "appreciation": "...",
  "tags": ["标签1", "标签2"],
  "key_figures": ["人物1", "人物2"],
  "historical_period": "..."
}
```
