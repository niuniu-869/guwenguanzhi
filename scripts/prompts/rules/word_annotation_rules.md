## 逐词注释核心规则

本规则同时适用于 LLM 生成管线与 Skill 推理，修改一处即两处同步。

### R1 · 词组切分标准

- **词组优先，非逐字**。典型词组长度 **1-4 字**。
- **可整体标注的长词组**：地名（"郑"）、人名（"郑武公"、"太史公"）、官职（"大司马"）、朝代（"春秋"）、明确的双字典故（"结草"、"衔环"）、典型复合词（"寤生"）。
- **禁止把"动宾/主谓/连动"短语当一个词**。错例：
  - ❌ `"亡其两骑"` 作为一个词条（应拆为 `亡 / 其 / 两 / 骑`）
  - ❌ `"斩汉一都尉"` 作为一个词条（应拆为 `斩 / 汉 / 一 / 都尉`）
  - ❌ `"燕雀安知鸿鹄之志哉"` 作为一个词条（全句，必须逐词拆）
- 虚词（之/乎/者/也/而/以/于/其/则/乃/为/所/且/若/焉/哉/矣/耳/兮/夫/盖/与）**一律单独标注**。
- 标点**不作为词条**。
- 所有词条 `word` 字段拼接后，**去除标点**必须等于原文**去除标点**。

### R2 · `type` 字段严格枚举（硬约束）

**只能使用以下 6 种之一，违反即视为无效输出**：

| type | 含义 | 覆盖范围 |
|---|---|---|
| `实词` | 名词、动词、形容词、数词、量词 | 年号、器物、爵位、物品等**归入实词** |
| `虚词` | 介词、连词、助词、语气词、代词 | 指示代词/人称代词**归入虚词** |
| `人名` | 历史人物姓名、字号 | 神名也归此类（如"黄帝"） |
| `地名` | 地理名称、国名、都邑 | 抽象地点（如"黄泉"）不算 → 归实词或典故 |
| `官职` | 官职、爵位职能 | 爵位归此类（如"诸侯""侯"） |
| `典故` | 典故、成语、固定短语 | 成语整体、典故整体均归此类（如"结草""皇天后土"） |

**禁止出现**：`成语`、`器物`、`年号`、`代词`、`名词`、`动词`、`词组`、`专名`、`短语`、`句子`、`书名`、`饮料`、`服饰`、`容貌`等任何此列表外的字符串。

### R3 · `meaning` 字段必须语境化

**禁止输出空泛释义**，必须结合本句具体内容。

#### 虚词（`之 其 何 焉 所 者 以 为 于 而 乎 也 矣 哉 乃 且 盖 夫 与`）特别要求：

- **必须说明本句中的具体语法功能或指代对象**
- 标准格式：`"<功能>，<具体解释>"`

对照示例：

| 原文 | ❌ 空泛错例 | ✅ 正确 |
|---|---|---|
| 公伐**诸**鄢（段） | "之于" | "合音字，相当于'之于'（指共叔段于鄢）" |
| 多行不义必自毙，子姑待**之** | "代词" / "它" | "代词，指共叔段的不义行为" |
| 其是**之**谓乎 | "助词" | "助词，宾语前置标志（'是之谓'即'谓是'）" |
| 王之不王，不**为**也 | "为" | "动词，做、施行" |
| 此则岳阳楼之大观**也** | "语气词" | "句末语气词，表判断与肯定" |
| 积土成山，风雨兴**焉** | "语气词" | "兼词，相当于'于此'" |

### R4 · 多音字必须显式标注读音理由（并设 `highlight: "polyphone"`）

以下字**高发多音**，若出现必须在 `meaning` 中注明"此处读 X，义为…"：

```
亟 说 遗 骑 为 夫 与 强 识 舍 乐 恶 纵 数 中 重 见 语 相
属 朝 王 长 著 卒 不 宁 间 应 使 从 称 省 处 菲 度 和 缝
干 宿 冠 难 当 更 恶 好 分 将 教 量 磨 尽 空 累 落 闷 兴
```

标准格式：`"此处读 X，义为 <释义>"`

示例：
- 亟请于武公 → `"亟": {"pinyin": "jí", "meaning": "此处读 jí，义为屡次、多次（区别于 qì 之'急切'义）"}`
- 韩非作《说难》 → `"说难": {"pinyin": "shuì nán", "meaning": "此处'说'读 shuì，义为游说；'说难'即游说之难"}`
- 大叔段 → `"大叔": {"pinyin": "tài shū", "meaning": "此处'大'通'太'，读 tài；大叔即共叔段（庄公之弟）"}`

### R5 · 通假字必须显式标注通假关系（并设 `highlight: "loan"`）

若某字为通假字，`meaning` **必须以"通'X'，义为…"格式开头**：

| 原文 | ✅ 正确标注 |
|---|---|
| 段不**弟** | `"弟": {"pinyin": "tì", "meaning": "通'悌'，敬爱兄长"}` |
| 焉**辟**害 | `"辟": {"pinyin": "bì", "meaning": "通'避'，躲避"}` |
| 百废**具**兴 | `"具": {"pinyin": "jù", "meaning": "通'俱'，全部、都"}` |
| 果能**授**孙吴之略耶 | `"授": {"pinyin": "shòu", "meaning": "通'受'，学习掌握"}` |
| 兽者，可以为**罔** | `"罔": {"pinyin": "wǎng", "meaning": "通'网'，捕兽的网"}` |

### R6 · 古今异义必须显式对比

若词在下列**古今异义高危清单**中出现，`meaning` 必须以"古义：…（非今义'…'）"格式写，并设 `highlight: "ancient_today"`。清单外若本义属明显古今异义（学习者易误解为今义），亦须按同格式注释并设 `highlight: "ancient_today"`。

```
去 走 汤 再 绝 亲戚 妻子 牺牲 羹 阳 牧 谢 购 币 或 羞 属
穷 所以 卑鄙 中国 无论 可怜 虽然 然则 因为 不必 几何 丈夫
夫人 小人 君子 感激 烈士 丹青 形容 书生 经济 交通 抛弃
痛恨 开张 不过 祖父 大风 强盗 故事 非常 气候 学者 便宜
行李 风流 下车 秋毫 山东 河南 河北
爱 恨 涕 汤 池 假 病 次 鄙 致 微 幸 购 顾 克 涉 颇 除
假借 博学 绝伦 流涕 从而 公车 股肱 狐疑 方寸 纷纷 百姓
```

若词不在清单但**本义属明显古今异义**（学习者极易误解为今义），亦须按同格式注释并设 `highlight: "ancient_today"`。判断标准：今义不能放进本句且读不通。

示例：
| 原文 | ✅ 正确标注 |
|---|---|
| 弗敢**加**也 | `"加": {"meaning": "古义：夸大、虚报（非今义'增加'）"}` |
| 直**走**咸阳 | `"走": {"meaning": "古义：奔向、通达（非今义'行走'）"}` |
| 牺牲玉帛 | `"牺牲": {"meaning": "古义：祭祀用的纯色牲畜（非今义'舍身'）"}` |
| 先帝不以臣**卑鄙** | `"卑鄙": {"meaning": "古义：身份低微、见识浅陋（非今义'品德败坏'）"}` |

### R7 · 固定结构整体标注（并设 `highlight: "fixed"`）

`fixed` 采用**严格白名单**。只有形式与下表一致或为下表模板的具象实例，方可标 `fixed`：

#### R7 白名单（精确形式）

| 结构 | 含义 | 例 |
|---|---|---|
| 所以 / 之所以 | 用来…的 / …的原因 | "所以传道受业解惑也" |
| 是以 / 以是 / 由是 / 是故 | 因此 / 所以 | "是以众议举宠为督" |
| 有以 / 无以 | 有/没办法 | "无以致疑也" |
| 孰与 | 和…比怎么样 | "孰与君少长" |
| 与其…孰若 / 与其…宁 | 与其…不如 | "与其生而无义，孰若死而荣" |
| 无乃…乎 | 恐怕…吧 | "无乃尔是过与" |
| 不亦…乎 | 不是…吗 | "不亦说乎" |
| 何…之有 | 有什么…（宾语前置） | "何厌之有" / "何罪之有" |
| 若…之何 / 如…之何 / 奈…何 | 对…怎么办 | "如太行王屋何" |
| 夫…者…也 | 所谓…是… | "师者所以传道受业解惑也" |
| 若夫 / 至若 / 且夫 | 发语词，用于引起下文论题 | "若夫淫雨霏霏" / "且夫水之积也不厚" |
| 然则 | 既然这样，那么 | "然则何时而乐耶" |
| 既而 | 不久之后 | "既而大叔命西鄙" |

`何…之有` 类的**具象实例**（"何罪之有"/"何厌之有"）整体标 `fixed`，`meaning` 说明其属"何…之有" 类宾语前置。

#### R7.1 · `fixed` 硬边界（**严禁滥用**）

`fixed` **仅限上表白名单**，下列情形**一律不归 `fixed`**：

| 情形 | 正确处理 |
|---|---|
| 成语 / 典故（"作奸犯科""不知所云""计日而待"） | `type: "典故"`，**不设** `highlight` |
| 一般复合词（"猥自枉屈""尔来""事无大小""所从来"） | `type: "实词"` 或 `"虚词"`，**不设** `highlight` |
| "不+X"（"不宜""不当""不足""不胜"）/ "何+X"（"何为""何以"） | `type: "虚词/实词"`，**不设** `highlight` |
| 兼词（"诸"="之于"、"焉"="于之"） | `type: "虚词"`，**不设** `highlight` |
| 动宾短语（"不以为然""无所适从""以为""至于"） | 按词拆分标注，**不设** `highlight` |
| 现代汉语仍在用的短语（"如此""至于""以来""以为""之""得无"） | 按普通虚词/实词处理，**不设** `highlight` |

**自检**：若你想标 `fixed`，先在 R7 白名单逐条对照 —— **对不上就必须设 `null`**。
特别警告：下列词是**高发错标 fixed**，**绝对不允许**标 fixed：
```
事无大小 · 以为 · 以来 · 至于 · 不胜 · 得无 · 何为 · 何极 · 如此 · 所从来 · 之 · 有所
```

#### R7.2 · R6 / R7 冲突处理

若某词同时满足 R6（古今异义清单）与 R7（固定结构），**一律按 R6 归 `ancient_today`**，不标 fixed。典型：
- `无论`：R6 清单词，古义"不要说"，今义"不管"。→ 标 `ancient_today`
- `然则`、`既而`、`且夫`：不在 R6 清单，按 R7 归 fixed

#### R7.3 · 反问句式的拆分原则

反问句式（如 `非…者乎` / `不亦…乎` / `何…之有`）：

- `不亦…乎` / `何…之有` 等有**多字连写的固定词形**（如 "何厌之有" / "何罪之有"）→ 整体标 `fixed`
- `非…者乎`、`岂…哉` 等句式**由零散虚词构成**（`非` / `者` / `乎` / `岂` / `哉` 各自独立）→ **每个虚词单独标为 `虚词`，不设 highlight**；仅在 `meaning` 里说明其参与的句式角色（"与 `非` 配合构成反问"）

### R8 · 专名必须有信息量

`type` 为 `人名/地名/官职/典故` 时，`meaning` 不得只复述词形。必须补充：

- **人名**：朝代 + 身份 + 本文中的角色
  - ✅ `"郑武公": {"meaning": "春秋初期郑国国君（前770-前744在位），庄公与共叔段之父"}`
  - ❌ `"郑武公": {"meaning": "郑国武公"}`
- **地名**：位置 + 性质
  - ✅ `"鄢": {"meaning": "春秋郑国地名，在今河南鄢陵，共叔段逃奔之地"}`
- **官职**：职责简介
  - ✅ `"封人": {"meaning": "掌管边境疆土的官员"}`
- **典故**：核心情节 + 出处
  - ✅ `"结草": {"meaning": "典出《左传·宣公十五年》，魏颗结草绊倒秦将杜回以报恩，喻死后报恩"}`

### R9 · 最小 `meaning` 长度 & 最大长度

- 虚词、古今异义、多音字、通假字：**至少 10 字**（含必要说明）
- 专名：**至少 8 字**（含身份/职责/情节）
- 普通实词：**5-20 字**为宜
- 任何词条：**不得超过 80 字**（超长说明设计错误）

### R11 · 罕用义标注（并设 `highlight: "rare"`）

若某字/词**本义属生僻或在现代汉语几乎不用该义项**（例如"丁"用作"人口"、"属"用作"叮嘱"、"将"用作"扶持"等），`meaning` 必须以 `罕用义：…` 开头，并设 `highlight: "rare"`。

判断标准（满足其一即可）：
- 现代常用词典（《现代汉语词典》）不收录该义项，或标为〔古〕
- 本字在本句中的义项与现代汉语常见义项完全断开，需额外解释方可理解
- 属于训诂学常识范围但非基础教育覆盖

**不归 `rare` 的情形**：
- 单纯的词类活用（名词用作动词、形容词使动等），若今义仍可推出古义，**不设** `highlight`；仅在 `meaning` 里说明"名词活用为动词"即可
- 专名（人名/地名/官职）即便罕见，仍按 §R8 写信息量，**不设** `highlight`
- 若同时满足 R6 古今异义条件，优先归 `ancient_today`，不归 `rare`（避免同一字在一篇内两种标记混用）
- **虚词一律不得设 `highlight: "rare"`**。虚词的语法功能（介词/语气词/连词等）即便古代专用，也应通过 §R3 语境化 `meaning` 说明，**不标 rare**。典型误标：`乎 / 之 / 以 / 于 / 而 / 为 / 其 / 所 / 乃 / 焉 / 哉 / 矣 / 耳 / 兮 / 夫 / 盖 / 与 / 庶 / 咸 / 卒 / 方 / 莫 / 耶 / 也 / 几 / 诚 / 岂 / 殆 / 向 / 尚 / 每`。这些虚词**只能**按 R4（多音）/R5（通假）/R3（虚词语境化）处理，**禁入 rare**。

示例：
| 原文 | ✅ 标注 |
|---|---|
| 十有五年而**志**于学 | `"志": {"meaning": "罕用义：立志、心志所向（非今义'志向'名词化）", "highlight": "rare"}` |
| 百**工**居肆 | `"工": {"meaning": "罕用义：工匠、手工业者（非今义'工作'）", "highlight": "rare"}` |
| **殆**有甚焉 | `"殆": {"meaning": "罕用义：恐怕、大概（副词）", "highlight": "rare"}` |

> **R6（古今异义）与 R11（罕用义）的区分**：R6 强调"今义存在、但本句必须按古义"；R11 强调"今义已基本不用该义项"。若两条都适用，优先 R6。

### R13 · `highlight` 字段规则（与前述条款联动）

`highlight` 为**可选字段**，枚举六选一（含 null）：

| 值 | 触发条件 | 联动规则 |
|---|---|---|
| `ancient_today` | 古今异义 | R6 |
| `loan` | 通假字 | R5 |
| `polyphone` | 多音字（非通读） | R4 |
| `rare` | 罕用义 / 生僻本义 | R11 |
| `fixed` | 固定结构 | R7 |
| `null`（或省略） | 普通词，无需特殊提示 | — |

**硬约束**：
- `highlight` 只能使用以上 5 种枚举值或省略/为 `null`
- 一个词条**至多一个** `highlight` 值（若多条适用，按优先级：`ancient_today > loan > polyphone > fixed > rare`）
- 普通实词、虚词、专名（人名/地名/官职）**不得**设 `highlight`（除非同时满足上列条件之一）
- 缺省即视为 `null`；前端据此判断是否加视觉标记

### R10 · 自检清单（模型自查）

输出前自检：

- [ ] 所有 `type` 都在 6 种枚举内
- [ ] 所有 `word` 拼接（去标点）等于原文（去标点）
- [ ] 虚词不是"代词""助词""语气词"这种空泛词
- [ ] 多音字都写了"此处读 X"，并设 `highlight: "polyphone"`
- [ ] 通假字都写了"通'X'"，并设 `highlight: "loan"`
- [ ] 古今异义高危词都写了"古义…（非今义…）"，并设 `highlight: "ancient_today"`
- [ ] 罕用义词以 `罕用义：` 开头，并设 `highlight: "rare"`
- [ ] 固定结构整体标注，并设 `highlight: "fixed"`
- [ ] `highlight` 只出现 5 种合法值或省略
- [ ] 没有把整句或动宾短语作为一个词条
- [ ] `sentences` 数组**不为空**，`words` 数组**也不为空**
