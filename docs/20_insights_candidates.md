## 一、用人（10 候选）

### 01. 萧何月下追韩信 🎯 识才要给舞台
- **情境**：韩信怀才不遇逃走，萧何不顾夜深亲自追回，劝刘邦"必欲争天下，非信无所与计事者"
- **出处**：《史记·淮阴侯列传》
- **当代类比**：核心人才离职前的挽留；不仅要识别天才，还要把"天才舞台"摆给他
- **三标签**：【史实】原文明载；【演绎】识人+用人是两件事；【推断·建议】核心人才流失前一定有信号，关键是老板愿不愿意"月下去追"

### 02. 刘邦论三杰 🎯 自知比自强重要
- **情境**：刘邦总结胜利："夫运筹策帷帐之中张良，镇国家抚百姓萧何，连百万之军战必胜攻必取韩信，吾皆不如。吾能用之，此吾所以取天下也"
- **出处**：《史记·高祖本纪》
- **当代类比**：CEO 的核心能力不是"全能"，是"知道自己哪里不行 + 招到补位的人"
- **三标签**：【史实】原文明载；【演绎】创始人的"自我定位"比"能力覆盖"更关键

### 03. 齐桓公用管仲 🎯 容仇用才
- **情境**：管仲曾射齐桓公中带钩，桓公即位后不报仇反拜相，终成春秋首霸
- **出处**：《史记·管晏列传》《左传·庄公九年》
- **当代类比**：招聘时遇到"过去得罪过你的人"或"和竞争对手关系密切的人"，能否放下旧怨
- **三标签**：【史实】明载；【演绎】仇人 → 合作者的转化需要"共同利益大于旧怨"；【推断·建议】放下旧怨的成本通常被高估

### 04. 秦穆公以五羊皮赎百里奚 🎯 跨界挖角
- **情境**：秦穆公得知百里奚为奴，不直接索要（怕对方抬价），用五张羊皮"赎回"，拜为大夫
- **出处**：《史记·秦本纪》
- **当代类比**：挖角对手团队核心时的姿态/路径设计；不要让对方知道你"急需"
- **三标签**：【史实】明载；【演绎】信息不对称下的定价艺术

### 05. 李世民用魏征 🎯 反对者留身边
- **情境**：魏征曾劝李建成杀李世民，玄武门后李世民问"汝何为离间我兄弟"，魏征直答后被委任重用
- **出处**：《旧唐书·魏征传》《贞观政要》
- **当代类比**：合并/重组后的前敌对派系核心；最大敌人留身边比驱逐更稳
- **三标签**：【史实】明载；【演绎】对立面能被"纳入系统"就不再是威胁

### 06. 商鞅三见秦孝公 🎯 试探老板格局
- **情境**：商鞅先说"帝道"（尧舜）秦孝公睡着，再说"王道"（三代）不感冒，最后说"霸道"（强国）才引起兴趣
- **出处**：《史记·商君列传》
- **当代类比**：pitch 投资人/老板时多准备几套方案试探真实胃口
- **三标签**：【史实】明载；【演绎】口是心非的决策者很多，得看他"眼神亮的是哪版"

### 07. 汉文帝拜周勃 🎯 新君对老臣
- **情境**：周勃迎立文帝有功，文帝先拜为右丞相赐金，后因周勃言语傲慢含糊罢相；周勃一度恐惧谋反嫌疑，最终免罪
- **出处**：《史记·绛侯周勃世家》
- **当代类比**：新 CEO 接手创始团队元老；既要用又要防，最怕"恃功"
- **三标签**：【史实】明载；【演绎】"授权—制衡"循环

### 08. 霍光拥立汉宣 🎯 权臣的"边界感"
- **情境**：霍光废昌邑王立宣帝，权倾朝野；宣帝亲政后"芒刺在背"，霍家后被族灭
- **出处**：《汉书·霍光金日磾传》
- **当代类比**：老臣与新主的"边界感"是老臣自己的责任
- **三标签**：【史实】明载；【演绎】权力真空期的"定鼎者"很难善终

### 09. 曹操官渡焚信 🎯 不追究异心
- **情境**：官渡胜袁绍后，缴获许多部下与袁绍私通书信，曹操当众焚毁不看
- **出处**：《三国志·武帝纪》《资治通鉴·汉纪》
- **当代类比**：公司危机时员工"骑墙"行为的处理；翻旧账只会让更多人跳船
- **三标签**：【史实】明载；【演绎】集体赦免的政治成本最低

### 10. 郭子仪宽厚免祸 🎯 功臣的低姿态
- **情境**：郭子仪平安史之乱功盖天下，对下属宽厚、对上恭顺、对同僚不争，家门常开、奴婢奴仆皆可进出，以示无秘密；最终 85 岁寿终正寝
- **出处**：《旧唐书·郭子仪传》
- **当代类比**：功高震主时的姿态管理；"无秘密"比"有靠山"更安全
- **三标签**：【史实】明载；【演绎】透明 = 无威胁感

## 二、变革（6 候选）

### 11. 商鞅南门立木 🎯 建立信用再推硬改
- **情境**：变法前在南门立木赏金十两，无人信，加到五十两，有人试搬，立赏，"民信乃立"
- **出处**：《史记·商君列传》
- **当代类比**：推行艰难改革前先做一件"小但必兑现"的事建立信任
- **三标签**：【史实】明载；【演绎】信任是变革的前置成本

### 12. 王安石变法节奏失控 🎯 操之过急
- **情境**：熙宁变法青苗/免役/保甲诸法同时推行，新党急于求成、反对派集结，最终神宗去世后尽废
- **出处**：《宋史·王安石传》
- **当代类比**：组织变革"多管齐下" vs "逐步推进"的权衡
- **三标签**：【史实】明载；【演绎】正确的方向也会输给错误的节奏

### 13. 张居正一条鞭法身后清算 🎯 成果与反弹
- **情境**：张居正推一条鞭、考成法，生前成效显著；死后被万历清算，尸位抄家，改革多废
- **出处**：《明史·张居正传》
- **当代类比**：强人推改革的"终身依附"问题；必须培养能延续改革的下一代
- **三标签**：【史实】明载；【演绎】改革绑在人身上不稳

### 14. 赵武灵王胡服骑射 🎯 妥协反对派的形式
- **情境**：推胡服骑射遇宗室反对，武灵王亲自做通叔父公子成的思想工作，形式上给足尊重，实质推进改革
- **出处**：《史记·赵世家》《战国策》
- **当代类比**：对元老派系改革时的"形式妥协 + 实质推进"
- **三标签**：【史实】明载；【演绎】反对者要面子不要里子时给面子

### 15. 王莽改制理想主义翻车 🎯 脱离实际
- **情境**：王莽托古改制，复井田、禁奴婢、乱改币制和官名，天下大乱
- **出处**：《汉书·王莽传》
- **当代类比**：理想主义驱动的顶层设计脱离市场反馈
- **三标签**：【史实】明载；【演绎】理想 ≠ 可行

### 16. 宋太祖杯酒释兵权 🎯 危机的温和化解
- **情境**：宋初五代骄兵之患，太祖一席酒宴让石守信等老将"告老还乡"，不流血解兵权
- **出处**：《宋史·太祖本纪》《续资治通鉴长编》
- **当代类比**：合伙人股权回收 / 元老退场的非对抗方案
- **三标签**：【史实】明载；【演绎】给足退路比强硬裁撤便宜

## 三、决策与危机（9 候选）

### 17. 项羽鸿门不杀刘邦 🎯 仁慈的代价
- **情境**：鸿门宴上范增屡次示意杀刘邦，项羽犹豫不决，放走
- **出处**：《史记·项羽本纪》
- **当代类比**：面对未来最大竞争对手的早期无害状态，是否"先下手"
- **三标签**：【史实】明载；【演绎】"关键决策点 × 错过即终身"

### 18. 韩信背水一战 🎯 置之死地而后生
- **情境**：韩信背水列阵破赵，主动放弃退路逼全军死战
- **出处**：《史记·淮阴侯列传》
- **当代类比**：创业孤注一掷 / 断后路逼团队成长
- **三标签**：【史实】明载；【演绎】有用但高风险；只适合领军者自信可控时

### 19. 诸葛亮用马谡失街亭 🎯 关键岗用错人
- **情境**：首次北伐关键隘口街亭，诸葛亮违众用马谡（善谋但无实战），失守街亭，北伐崩盘
- **出处**：《三国志·诸葛亮传 / 马谡传》
- **当代类比**：把"能言善辩"的人放到需要"硬落地"的关键岗
- **三标签**：【史实】明载；【演绎】战略级岗位的人选容错为零

### 20. 曹刿论战一鼓作气 🎯 时机的把握
- **情境**：长勺之战曹刿"一鼓作气，再而衰，三而竭"，趁齐三次击鼓之后反攻
- **出处**：《左传·庄公十年》
- **当代类比**：竞争对手重大发布后的心理学窗口
- **三标签**：【史实】明载；【演绎】时机 > 兵力

### 21. 赵括纸上谈兵 🎯 理论派接手灾难
- **情境**：长平之战赵王用赵括代廉颇，赵括空谈兵法、刚愎自用，40 万赵军被坑杀
- **出处**：《史记·廉颇蔺相如列传 / 白起王翦列传》
- **当代类比**：MBA 新锐空降老厂，推翻老规矩出灾难
- **三标签**：【史实】明载；【演绎】理论与"脏活"的鸿沟

### 22. 田单火牛破燕 🎯 绝境的创造性
- **情境**：即墨被燕围困五年，田单用火牛阵奇袭，大败燕军复齐
- **出处**：《史记·田单列传》
- **当代类比**：公司濒死时的非常规创新；常规打法已被验证无效时不要再按常规
- **三标签**：【史实】明载；【演绎】穷则变，变则通

### 23. 崇祯杀袁崇焕 🎯 疑人不用的代价
- **情境**：袁崇焕督师蓟辽，后被皇太极"反间计"诬陷，崇祯将其凌迟；明朝辽东防线从此崩
- **出处**：《明史·袁崇焕传》
- **当代类比**：对关键岗位负责人因"流言"动摇
- **三标签**：【史实】明载；【演绎】"将在外，君命有所不受" vs 监军过度

### 24. 汉景帝杀晁错 🎯 危机中的替罪羊
- **情境**：七国之乱起，景帝杀力主削藩的晁错"以谢天下"，乱仍不止
- **出处**：《史记·袁盎晁错列传》
- **当代类比**：危机时牺牲"正确但不合时宜"的骨干以平息外部压力
- **三标签**：【史实】明载；【演绎】替罪羊策略短期有效长期动摇人心

### 25. 勾践卧薪尝胆 🎯 长期隐忍
- **情境**：越王勾践为吴王夫差奴仆三年，归国后十年生聚十年教训，终灭吴
- **出处**：《史记·越王勾践世家》《吴越春秋》
- **当代类比**：彻底失败后的长周期复盘重建
- **三标签**：【史实】《史记》有载，部分细节（尝胆）见野史；【演绎】时间是弱者最强武器

## 四、自处与人际（10 候选）

### 26. 范蠡急流勇退 🎯 功成身退
- **情境**：范蠡助勾践灭吴后，弃官经商号"陶朱公"三致千金；写信劝文种"飞鸟尽良弓藏"，文种不听遭诛
- **出处**：《史记·越王勾践世家 / 货殖列传》
- **当代类比**：退出机制 / 创始人退休姿态
- **三标签**：【史实】明载；【演绎】最好的退出时机在巅峰不在下坡

### 27. 韩信不反 终被诛 🎯 对领导的信任错觉
- **情境**：蒯通劝韩信三分天下，韩信感刘邦"解衣衣我推食食我"之恩不听；后被吕后诱杀未央宫
- **出处**：《史记·淮阴侯列传》
- **当代类比**：员工/合伙人对领导的个人恩情错判为组织保护
- **三标签**：【史实】明载；【演绎】"功高不赏"是组织规律不是个人恩怨

### 28. 萧何自污保命 🎯 功臣的自降
- **情境**：萧何为消刘邦猜忌，强买民田、故意留"贪名"，反而免祸
- **出处**：《史记·萧相国世家》
- **当代类比**：权力中心附近的"故意不完美"策略
- **三标签**：【史实】明载；【演绎】完美 = 威胁

### 29. 张良功成辟谷 🎯 主动淡出
- **情境**：张良助刘邦定天下后"愿弃人间事，从赤松子游"，辟谷养生不问政
- **出处**：《史记·留侯世家》
- **当代类比**：功成后主动交权、转向个人追求
- **三标签**：【史实】明载；【演绎】权力的"旋转门"由自己而非别人控制

### 30. 李斯与赵高合谋 🎯 一念之差的代价
- **情境**：秦始皇沙丘崩，李斯原本要按遗诏立扶苏，被赵高说动合谋立胡亥；后李斯被赵高诬陷腰斩夷三族
- **出处**：《史记·李斯列传》
- **当代类比**：在关键岔路选"妥协共谋"，最终被同盟者反噬
- **三标签**：【史实】明载；【演绎】"一次共谋"永远留下把柄

### 31. 廉颇蔺相如将相和 🎯 和解优于内斗
- **情境**：蔺相如以退为进，避廉颇车；廉颇得知其"先国家之急而后私仇"，负荆请罪
- **出处**：《史记·廉颇蔺相如列传》
- **当代类比**：高管内斗；主动示弱者反而赢得尊重
- **三标签**：【史实】明载；【演绎】格局差决定和解可能性

### 32. 信陵君窃符救赵 🎯 越级担责
- **情境**：魏王不肯发兵救赵，信陵君窃兵符、杀晋鄙、率八万魏军救赵于邯郸；事后被魏王猜忌不敢归
- **出处**：《史记·魏公子列传》
- **当代类比**：绕过直属上级做"正确但越权"的事
- **三标签**：【史实】明载；【演绎】越权救大局的代价是被原组织排斥

### 33. 苏秦合纵六国的脆弱 🎯 联盟的脆弱
- **情境**：苏秦合纵六国抗秦，佩六国相印十五年；秦国远交近攻各个击破，联盟瓦解
- **出处**：《史记·苏秦列传》《战国策》
- **当代类比**：反垄断联盟 / 多方合作的易碎性
- **三标签**：【史实】明载（苏秦事迹细节有争议）；【演绎】共同敌人是联盟唯一粘合剂

### 34. 赤壁孙刘联盟 🎯 敌人的敌人
- **情境**：曹操南下逼迫，孙权刘备临时结盟赤壁大破曹军；战后因荆州归属又反目
- **出处**：《三国志·周瑜传 / 先主传》
- **当代类比**：面对共同威胁的短期结盟 + 威胁解除后的快速决裂预案
- **三标签**：【史实】明载；【演绎】结盟时就应该备好分手条款

### 35. 毛遂自荐 🎯 主动争取
- **情境**：平原君赴楚求救，选 20 人少一人，毛遂自荐说"锥处囊中其末立见"，楚赵定盟
- **出处**：《史记·平原君虞卿列传》
- **当代类比**：被忽视但自信的员工如何"破局"；主动 pitch 比等发现有效
- **三标签**：【史实】明载；【演绎】"被看见"是候选人自己的责任
