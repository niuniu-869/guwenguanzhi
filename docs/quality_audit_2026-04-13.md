## 严重问题（必须修复）

### 1. `tang/118_阿房宫赋.json` — 原文录入错字

句："一肌一容，尽态极**姘**，缦立远视" → 通行本应作"极**妍**"（yán，美丽）。

"姘"（pīn）义为私通，使句意完全走样；注音 `jí pín`、释义"极其美丽"皆基于错字硬解。

**建议核对全部底本原文**。

### 2. `pre_qin/008_曹刿论战.json` — 词注释与翻译矛盾的古今异义

句："犠牲玉帛，弗敢**加**也，必以信"。

整段翻译作"不敢虚报"（正确，"加"古义=夸大、虚报），但词注释 `加(jiā): 增加` 给出**今义**。用户点开会发现翻译和注释打架。

同段："犠牲"作为整体释为"祭祀用品"——"牺牲"是最常被误解的古今异义关键词，应单独拆出说明"古指祭祀用纯色牲畜，与今义'舍身'不同"。

### 3. `ming/208_卖柑者言.json` — 关键动词反向错译

句："果能**授**孙、吴之略耶？" 注释 `授(shòu): 传授`。**错。**

此处刘基讥讽武将，意为"果真能**学到/掌握**孙武吴起的兵法吗"，"授"应通"受"（接受、习得）。当前释义把讥讽完全译反。

### 4. `shiji/007.json`（项羽本纪）— 多音字"骑"前后矛盾且空注

句："项王乃驰，复斩汉一都尉……复聚其骑，**亡其两骑**耳"。

`骑(qí): 骑兵` 与 `亡其两骑(wáng qí liǎng qí): 损失了他的两匹马` 同句两释；"骑"作"一人一马的合称"应读 **jì**，被错标为 qí。

全库扫描：骑 qí 43 处 / jì 21 处，比例混乱。

### 5. `pre_qin/001_郑伯克段于鄢.json` — 多音字+词性双错

- "亟请于武公" 中 `亟(qì): 屡次 [虚词]`。"亟"作"屡次"应读 **jí**，作 qì 时义"急切"，注音错；又"屡次"是副词，归"虚词"也存疑。
- "**大叔**段" 全文按 `dà shū` 标注，但古注"大"通"太"，应读 **tài shū**（即《左传》"太叔"）。出现 8+ 次均错。
- "**段不弟**" 中"弟"通"悌"，应读 tì 释"敬爱兄长"，被简注为 dì "弟弟的道义"，通假关系完全失落。

### 6. `shiji/063.json` — 同一篇名两套注音

"韩非作《**说难**》"注 `shuō nán`；同段又出现 `shuì nán`。"说难"作书名取游说义，应统一 **shuì nán**。

### 7. 空 `words` 数组（126 个文件 / 297 句）

全库 39528 句中有 **297 句（0.75%）的 words 数组完全为空**，分布在 126 个文件中。其中：

- `shiji/007.json` 鸿门宴关键句"沛公奉卮酒为寿，约为婚姻……籍吏民，封府库，而待将军"无任何词注释。
- `pre_qin/057_苏秦以连横说秦.json` 多达 13 句空注。
- `pre_qin/001` 的"多行不义必自毙"、"子姑待之"、"其是之谓乎"三句皆空。

这是 LLM 在长句或特殊标点（双引号嵌套）下静默失败，必须重跑修补。

### 8. `pre_qin/001` — 专名 type 错标

- "君将不堪"中 `君(jūn): 您 [人名]`、"况君之宠弟乎"中 `君: 君主 [实词]`——同一字两套 type。

## 一般问题（建议修复）

### 1. 关键古今异义未做提示

- `tang/118` "直**走**咸阳"——"走"被合并到"直走"中按今义"直通"译过，避开了"走 = 奔向、通到"这个高考必考点。
- `shiji/063` "兽，吾知其能**走**"——翻译对（跑），但词注合并未单拆"走"。
- 多篇"再"="第二次"标对了（如曹刿"再而衰"），但未提示古今异义，遗憾。

### 2. 专名释义信息量不足

- `ming/208` "类**东方生**滑稽之流"——东方生即东方朔，应在 meaning 里点出"汉武帝时人，以滑稽善辩著称"，否则现代读者完全无法 get 到讽刺梗。
- `wei_jin/105` "**结草**"释为"报恩典故"——典故内容未展开（《左传》魏颗故事），读者依然不知所云。
- "**陛下**" type 标"官职"——错，应为"称谓/尊称"。
- "**皇天后土**" type 标"典故"——其实是固定短语。

### 3. 释义笼统，未结合本句

- `pre_qin/001` "公伐**诸**鄢" `诸(zhū): 之于`——告诉用户合音字身份是好的，但不告诉读者本句"诸 = 之（他，指段）+ 于（在）"，用户仍然懵。
- "若之何" 拆为 `若(若如何) + 之(代词) + 何(什么)`——把固定结构"对…怎么办"拆得碎片化，反而看不懂。
- `tang/118` "钩心斗角"按现代成语义打散为 `钩心: 结构交错 + 斗角: 檐角相对`，本义建筑学含义保留了，但成语化今义未提示，可能误导。

### 4. 词组拆合标准不一

- `shiji/007` "斩汉一都尉" / "杀数十百人" / "亡其两骑" 整句作为一个词条——严重违反逐词标注原则。
- `pre_qin/001` "京城大叔" 当一整词标 `实词`，但其中"大叔"应单独拆并注 tài。
- `tang/118` 把"五步""一楼"拆开但又把"北构"合成一词，规则混乱。

### 5. 赏析/背景小瑕疵

- `pre_qin/001` 赏析"多行不义必自**毙**"——原文"毙"是"倒下/垮台"，标题处转写时未引号闭合且省略"等成语流传至今"前的引号。
- `tang/118` 背景说"约作于唐敬宗宝历年间（公元825年左右）"——杜牧《阿房宫赋》序自署作于唐敬宗**宝历元年**（825年），可接受；但"晚唐"略不准，杜牧时代仍属中晚唐过渡，措辞可更精确。

## 系统性模式（最有价值）

通过全 352 篇统计扫描得出：

### 模式 A：`type` 字段类型系统失控（最严重）

schema 规定 6 种 `type`，实际全库出现 **40+ 种**：

```
实词 261417, 虚词 100547, 人名 42294, 地名 23291, 官职 6909,
典故 3403, 成语 2421, 器物 2231, 年号 770, 词组 97, 名词 54,
专名 31, 代词 18, 实词短语 17, 动词 16, ...
```

LLM 自由发挥引入"成语""器物""年号""动词""短语""书名""饮料""服饰"等。前端如果按 6 种渲染，多余类型必然显示异常。**急需修复**。

### 模式 B："之"字 81.8% 极简释义

全库 16900 个"之"中，**13831 个（81.8%）** 的 meaning 仅为"它/他/的/代词/助词"等空泛词，**未指明具体指代什么**。

这正是用户反馈"标了还是看不懂"的根因。同样问题大概率存在于"其、何、焉、所、者、乃、夫、以"等高频虚词。

### 模式 C：多音字识别能力中等偏弱

按全库统计：

- 「亟」99% 标 jí（含本应读 qì 的语境） — 倾向单一发音
- 「骑」qí:jì = 43:21 — 区分但混乱
- 「夫」fú:fū = 722:121 — 大致对，但"丈夫/夫人"语境少
- 「乐」lè:yuè ≈ 1.2:1 — 较好
- 「为」wéi:wèi = 5777:1072 — wèi 偏少（许多介词"为"该读 wèi）
- 「与」yǔ:yú:yù = 2772:54:12 — yù（参与）严重不足

### 模式 D：通假字几乎从不显式标注

抽查"段不弟"（弟通悌）、"焉辟害"（辟通避）、"百废具兴"（具通俱）、"走者可以为罔"（罔通网）、"果能授孙吴"（授通受），**全部未在 meaning 中标"通某字"**，仅给出意译，丧失训诂价值。

### 模式 E：关键句的句译时常"漂亮但不精确"

LLM 倾向于产出读起来流畅的"翻译"，但回到逐词时露馅：

- 段译用了对的古义（"加"=虚报），词注释回到今义（"加"=增加）。
- 段译合并意译"果真能学到孙吴谋略"，词注释把"授"标"传授"——段译本身也有错，但词注释错得更明显。

### 模式 F：固定结构被拆碎

"若…之何"、"何…之有"、"取而代之"、"莫…不"、"无乃…乎"等固定结构常被逐字拆开标注，丧失语法识别。

## Prompt 改进建议（可立即落地）

### 1. 强约束 type 枚举值

在 prompt 末尾加：

> `type` 字段**严格只能**取这 6 个值之一：实词/虚词/人名/地名/官职/典故。任何其他字符串（如'成语''器物''代词''年号''官职号'）都禁止。年号归'实词'，成语整体归'典故'，物品名归'实词'。

### 2. 强制虚词必须语境化释义

> 对"之、其、何、焉、所、者、以、为、于、而、乎、也、矣、哉、乃、且、盖、夫、与"等虚词，meaning **必须包含本句中的具体指代或语法功能**，禁止只写"代词""助词""语气词""的""它"。
>
> 例：
> - "之"指代谁→"他（指共叔段）"
> - "也"表什么语气→"表判断，相当于'是'"
> - "焉"是疑问/兼词/语气→"兼词，相当于'于此'"

### 3. 多音字与通假字必须显式标注

> 若该字为多音字（含但不限于：亟/说/遗/骑/为/夫/与/强/识/舍/乐/恶/纵/数/中/重/见/语/相/属/朝/王/长/著/卒/不），meaning 中必须以"此处读 X，义为..."格式说明读音选择理由。
>
> 若为通假字，meaning 必须以"通'X'，义为..."格式开头，例如"弟：通'悌'，敬爱兄长"。

### 4. 古今异义白名单显式提示

> 若词在以下高频古今异义清单中出现，必须以"古义：…（区别于今义'…'）"格式注释：
>
> 去/走/汤/再/绝/亲戚/妻子/牺牲/羹/阳/牧/谢/购/币/或/羞/属/穷/所以/卑鄙/中国/无论/可怜/虽然/然则/因为/不必/几何/丈夫/夫人/小人/君子/感激/烈士/丹青/形容/书生/经济。

### 5. 空 words 与固定结构兜底校验

- 在 prompt 末尾加"自检：每个 sentence 的 words 数组**不得为空**，至少要为每个汉字给出释义；如果原句含引号、嵌套、长句，分多次输出但不要省略。"
- 增加"识别并整体标注的固定结构清单"：若…之何/何…之有/取而代之/无乃…乎/不亦…乎/孰与/所以/有以/无以/与其…孰若/虽然/虽则/夫…者…也。

### 6. 专名释义必须有信息量

> 对人名/地名/官职/典故，meaning 不得只复述词形（如"郑武公: 郑国武公"）。
>
> - 人名要给出朝代+身份+本句中地位（"郑武公：春秋郑国国君，庄公之父"）
> - 典故要简述核心情节（"结草：典出《左传》宣公十五年，魏颗结草绊倒杜回报恩"）
> - 官职要说明职责（"封人：管理边境疆界的官"）

## 整体评估

### 翻译可用率：约 85%

段落级整段翻译大多通顺达意，少量关键字误（加/授/走/夺）和原文录入错（姘/极姘）。读者读段译能基本理解大意。

### 词注释可用率：约 60–65%

实词字面释义大多正确，但：

- type 字段失控（schema 外类型 ≈ 5% 词条）
- 虚词 81.8% 给出空泛释义，对学习者价值低
- 通假/古今异义/多音字三大要害普遍未显式标注
- 0.75% 句子完全无 words 数组（126 个文件受影响）
- 词组拆分标准不一致

### 是否需要重跑：是

- **必须重跑**：所有 `words` 为空的 297 句（126 个文件），可定向修补而非全文重生成。
- **建议重跑**：先秦类（古今异义/通假最密集）、史记长篇列传（合并整句问题最严重，如项羽本纪）、唐宋赋体（专名密度高）。
- **可保留**：明清浅近文言（陈情表/卖柑者言/岳阳楼记等单点错误，补丁式修订即可）。
- 强烈建议**重跑前先按上面 6 条建议固化 prompt**，并增加 **JSON Schema 校验 type 枚举值**作硬约束，再针对性回流。
