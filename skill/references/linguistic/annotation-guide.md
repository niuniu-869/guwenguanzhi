# 古文注释层次指南

> 注释是为了让读者理解，不是炫学。**分层次、留必要、去多余**。

## 四层注释（从浅到深）

### 层 1：字词注音 + 简释
面向初学者，逐字标注重要音义。
- 例：`歼（jiān, 消灭）`
- 仅对**关键字 + 生僻字 + 易误字**标注
- 不要给所有字标音（会让文本臃肿）

### 层 2：句释（意译句义）
面向已能断句的读者，翻译每句大意。
- 例：`"以吾一日长乎尔，毋吾以也。" —— 不要因为我比你们年长就有所顾忌。`
- 结构：原文 + 意译

### 层 3：背景说明
面向想理解语境的读者，说明人物/事件/地点。
- 例：`子路（仲由，孔子弟子，比孔子小 9 岁，以勇闻名）`
- 仅对**首次出现**的关键实体注释；后续不重复

### 层 4：义理/考证
面向学术读者，讨论学派解读、异文、版本。
- 例：`关于"仁"的解释，朱熹主张"心之德、爱之理"，王阳明主张"心即理"...`
- **普通阅读场景不用这层**——它属学术注释范畴

## 注释的优先级

给定字数预算，优先级排序：

1. **古今异义词**（最易误读）
2. **人名/地名首次出现**（错位会崩全文）
3. **词类活用和特殊句式**
4. **典故**（引用前人时）
5. **字音**（仅保留生僻/多音）
6. **版本异文**（只在关键出入时）

## 注释格式规范

### 位置
- **夹注**：`[释义]` 紧跟原文词后，适合短注
- **脚注**：`[^1]` 放在段落末，适合长注/考证

### 示例：
```
【夹注】
"臣本布衣（平民）[^1]，躬耕于南阳（今河南南阳，诸葛亮避居之地）。"

【脚注】
[^1]：布衣：平民。古代没做官的人穿布做的衣服，故以"布衣"指代平民。
```

### 长度
- 夹注：≤ 10 字
- 脚注：≤ 100 字（超长建议拆成多个）

## 禁忌

### ❌ 信息密度过高
```
"项伯（项羽叔父，项梁之弟，名缠，字伯。后因救张良私会沛公，
  夜告张良刘邦将被击。鸿门宴上项伯亦拔剑起舞掩护刘邦。汉初
  封射阳侯，赐刘姓，谥哀）"
```
一个注一句话足够：`项伯（项羽叔父，通张良）`

### ❌ 循环注释
```
"布衣" 注 "平民"
"平民" 又注 "古代普通百姓"
"普通百姓" 又注 "既非贵族也非官吏"
```
只注一次即可。

### ❌ 主观评价
```
"先帝不以臣卑鄙（这里体现了诸葛亮的谦虚美德）"
```
注释管"原文意思"，不管"作者品德"。评价属赏析，另行分段。

### ❌ 今人意识形态注释
```
"舜发于畎亩之中（说明劳动人民能出伟人）"
```
不要用当代概念套古文。

## 不同文类的注释重点

### 史传（《史记》《汉书》）
- 重点：人物关系、地名对应、官职制度
- 示例：`宦者令缪贤（宦官头目缪贤）、赵奢（赵国名将，赵括之父）`

### 论说（《论语》《荀子》）
- 重点：学派脉络、关键概念
- 示例：`"仁"（孔子学说核心，这里指"爱人"的意思）`

### 诗赋（《楚辞》《赤壁赋》）
- 重点：典故溯源、意象
- 示例：`"美人（通常指君王，此处是屈原自喻或指楚怀王）"`

### 奏章（《出师表》《陈情表》）
- 重点：上下文、谦辞敬辞
- 示例：`"陛下（古代臣对君的敬称，意为殿阶之下，不敢直呼）"`

## 工具辅助注释生成

- 不确定人物背景？→ `lookup.py 人名`
- 不确定地名？→ `lookup.py --place 地名`
- 不确定事件？→ `timeline.py --year N`
- 某词是否词类活用？→ 查 [`common-traps.md`](common-traps.md)

## Agent 输出注释的标准格式

用户问"帮我注释这段古文"时：

```
原文：[完整段落]

释词：
- 字1（注音, 古义）
- 字2（注音, 古义）
...

句释：
[每句逐段意译]

注：
- 关键人物/地点/典故（每条 ≤ 50 字）
```
