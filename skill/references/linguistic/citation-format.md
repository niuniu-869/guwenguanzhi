# 引用规范

> **核心原则**：不可查即不可引。每一处"古人云"都必须能用 `cite.py` 校验出 URN。

## 标准引用格式

```
【书·卷号·卷名·段号】 或 【书·体裁·序号·段号】
```

### 数字 URN
```
【史记·卷008·高祖本纪第八·段003】
```

### 语义 URN
```
【史记·世家第二十五·段008】  → shiji/世家/25/008
```

## 引用时必备三要素

| 要素 | 说明 | 示例 |
|---|---|---|
| **原文** | 必须是底本原字，不得现代化改写 | "赤帝子斩白帝子" ✓<br>"红衣神子斩了白衣神子" ✗ |
| **出处** | 精确到卷（段可选） | `shiji/本纪/008` ✓<br>"史记上说" ✗ |
| **已校验** | 走过 cite.py / search.py | cite 返回的结果可直接用 |

## Agent 输出引用的模板

```
"臣本布衣，躬耕于南阳"
—— 诸葛亮《出师表》
(URN: 待补；此文未收入二十四史，可查《诸葛亮集》)
```

## 不同场景的引用选择

### 场景 A：现代咨询中引用历史
```
【史实】《史记·高祖本纪第八》载：刘邦入咸阳，"与父老约法三章"。
(URN: shiji/本纪/008/003，cite.py 已校验)
```

### 场景 B：古文阅读教学
```
《出师表》原文节选：
"臣本布衣，躬耕于南阳，苟全性命于乱世，
不求闻达于诸侯。"
```
无需 URN 但要原文精准。

### 场景 C：考据辨析
```
"鞠躬尽瘁，死而后已" 并非《前出师表》原文。
后出师表载："鞠躬尽力，死而后已，至于成败利钝，
非臣之明所能逆睹也。"
(后出师表版本归属有争议，见《三国志·诸葛亮传》裴注)
```
必须说明版本差异。

## 常见引用错误

### ❌ 1. 伪引
```
古人云：不忘初心，方得始终
```
这是现代人的话（华严经有"不忘初心"但原文作"不忘初心，得菩萨果"，语义不同）。
**修正**：若真要用，说清楚"这是现代常用语，古文中类似表达有..."

### ❌ 2. 张冠李戴
```
苏轼说："天下兴亡，匹夫有责"
```
这是顾炎武《日知录》的话。
**修正**：cite.py 找不到时不要强加作者。

### ❌ 3. 篡改原文
```
原：逝者如斯夫，不舍昼夜
错：时光如流水，不分昼夜
```
引用必须原文。若要意译，明确说"意译"。

### ❌ 4. 模糊出处
```
《史记》中写过：...
```
必须具体到某卷/某传/某本纪。
**修正**：《史记·高祖本纪》或 `shiji/本纪/008`。

### ❌ 5. 年代穿越
```
孔子说："江山如此多娇"
```
毛泽东《沁园春·雪》。孔子不可能用这种宋词形式。
**修正**：人物和文体时代必须匹配。

## 多源引用的优先级

同一事件多书记载时：

1. **二十四史优先**（如史记、汉书、三国志）
2. **《资治通鉴》次之**（编年体，时间核对）
3. **地方志/别史三之**（如《越绝书》《吴越春秋》）
4. **演义小说** ✗（三国演义、水浒传不能作史料）

## 工具联动

```bash
# 片段校验
python skill/scripts/cite.py --verify "你想引的原文"

# URN 取全文
python skill/scripts/cite.py shiji/世家/25

# 模糊搜索找出处
python skill/scripts/search.py "关键词" --limit 5

# 人物出处
python skill/scripts/lookup.py 张良
```

## 引用 vs 改写

当原文拗口想意译时，区分清楚：

```
【引用】 原文直接粘贴
"运筹策帷帐之中，决胜于千里之外，吾不如子房"

【引述】 改说且明示
刘邦在《史记·高祖本纪》中评价张良"能在帐中运筹，胜出千里"

【意译】 改换句式但核心意思不变
刘邦承认自己在战略规划上不如张良
```

三种可选，但**不能混淆**：引用必须一字不差，意译必须明示。
