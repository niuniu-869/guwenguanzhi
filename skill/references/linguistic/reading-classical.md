# 古文阅读方法论

> **定位**：带用户从"完全读不懂"到"能抽出文意"的路径。不是逐字翻译，是**读懂结构**。

## 古文不可读的三个真正原因

用户读不懂古文，通常不是"字不认识"，而是：

1. **古今异义**：字都认识，但今天的意思和原文不同（"妻子"=妻 + 子，"走"=跑）
2. **省略**：主语/宾语/介词被省（"将军击河北，臣战河南" = 将军 [击] 河北，臣 [战] 河南）
3. **语序颠倒**：宾语前置、定语后置、状语后置（"何陋之有" = 有何陋）

> 查陷阱细节 → [`common-traps.md`](common-traps.md)

## 三步阅读法

### Step 1：断句（最优先）

古文原文常无标点。找"而/之/也/矣/乎"等虚词，以及主谓宾结构转折处断句。

- **例**：`吾师道也夫庸知其年之先后生于吾乎` 
  → `吾师道也。夫庸知其年之先后生于吾乎？`
  → "我学的是道理，哪里管他的年纪比我大还是小呢？"

**工具支持**：现代版原文 `search.py` 返回的已是断句版本。

### Step 2：识别"主语省略"

古文最常见省略主语（尤其承前省）。每一句默认接续上一句主语。

- **例**：`项羽曰：壮士！赐之卮酒。则与斗卮酒。` 
  → 后两句主语都是项羽。
  → "项羽说：壮士！赐他一杯酒。（左右）于是给了他一大杯酒。"

### Step 3：抓住"连接词"和"转折"

- `而`：连词，可表并列/顺承/转折，要看上下文
- `则`：那么/就
- `虽`：即使（不是"虽然"）
- `然`：这样，也可作"然而"
- `所以`：用来...的；...的原因（非"因此"）

## 阅读不同文类的策略

### 史传类（《史记》《汉书》）
- **结构**：人物小传常按"出身 → 事迹 → 评价"三段
- **信号词**："初"（开头交代背景）、"太史公曰"（评语）、"于是"（转折）
- **策略**：先读首尾评语抓大意，再读中段关键事件

### 论说类（《论语》《孟子》《史论》）
- **结构**：议论常有"问 → 答 → 例 → 结"
- **信号词**："夫"（发语词，引出论点）、"故"（因此）、"然则"（既然如此）
- **策略**：找核心论点（通常在"故曰"或"是以"之后）

### 骈文/赋（《岳阳楼记》《前赤壁赋》）
- **结构**：对偶句为主，两两成对
- **策略**：一对一读，抓住对偶关系，不必逐字译

## 碰到不认识的字怎么办

1. **先推测**：从上下文+偏旁推字义
   - "阿谀" 不识 "谀"，看部首"言"，猜测与言语相关
2. **查 search.py**：把句子 search 一下看其他典籍对应释义
3. **最后查现代字典**：《古代汉语词典》或《说文解字》

**不要做的**：
- ❌ 直接套现代义（如把"走"译为"走路"）
- ❌ 忽略"也/矣/乎/哉"等语气词（它们影响句意强弱）
- ❌ 只读一遍——古文需要**默读 + 重读**

## 标准输出（给 agent 的规范）

用户问"帮我读懂 X"时，输出按此三段式：

```
1. 原文（保留原样）
2. 断句与释词（标出古今异义、省略、倒装）
3. 现代汉语意译（流畅版，一段一译）
```

**禁忌**：
- 不要只给翻译不给原文（用户无法对照）
- 不要逐字翻译（古文"走"译"行走"会荒谬）
- 不要省略"也/矣"等语气词的语气处理
