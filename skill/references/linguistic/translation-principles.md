# 古文翻译原则

> **准则**：信（忠实）、达（通顺）、雅（有韵味），三者优先级递减。

## 三个层级

| 层级 | 目标 | 示例 |
|---|---|---|
| **信** | 不错不漏 | "妻子" → "妻子儿女"（不能省儿女） |
| **达** | 现代汉语通顺 | "何陋之有" → "有什么简陋的呢"（不保留倒装） |
| **雅** | 保留文气节奏 | 骈文译文尽量对仗 |

**不得为了"达/雅"牺牲"信"**——宁可拗口也不能添意。

## 翻译 4 步

### Step 1：逐词释义
先把每个字的古意写出来，特别注意：
- 单字词 ≠ 现代双字词（古文"闻"=听/听说，"书"=写/信/书籍）
- 古今异义（"走"=跑）
- 引申义（"道"可以是道路/方法/道理/道教）

### Step 2：补充省略
主语/宾语/介词缺失要补回来。
- `沛公军霸上` → 沛公[驻]军[于]霸上
- `旦日不可不蚤自来谢项王` → [你]明天不可不早[一些]亲自来[向]项王谢[罪]

### Step 3：调整语序
- **宾语前置**：`何厌之有` → 有何厌 → 有什么满足
- **定语后置**：`蚓无爪牙之利，筋骨之强` → 蚯蚓没有锋利的爪牙，强健的筋骨
- **状语后置**：`战于长勺` → 在长勺作战

### Step 4：润色
- 文言虚词（也/矣/乎/哉/焉/耳）转换为现代语气（呢/啊/吗/罢了/而已）
- 排比/对偶适度保留
- 标点按现代规范

## 常见错误

### ❌ 错误 1：古今异义直接对等
```
原文：项庄拔剑起舞，项伯亦拔剑起舞，常以身翼蔽沛公。
错译：项庄拔剑起舞，项伯也拔剑起舞，经常用身体像翅膀一样掩蔽沛公。
正译：项庄拔剑起身起舞，项伯也拔剑起身起舞，时时用身体像张开翅膀一样遮护沛公。
```
"翼"是名词活用作状语，"翼蔽"是"像翅膀一样遮护"，不能译成"翅膀一样掩蔽"。

### ❌ 错误 2：省略未补
```
原文：廉颇闻之，肉袒负荆，至门谢罪。
错译：廉颇听了这事，赤膊背着荆条，到门口请罪。
正译：廉颇听到这事，赤着上身背着荆条，到[蔺相如]门前请罪。
```
"至门"是省略"蔺相如门"，不说清读者会困惑。

### ❌ 错误 3：过度直译
```
原文：以是人多以书假余。
错译：因此人多把书借给我。
正译：因此别人大多把书借给我。
```
"以是"是"因此"、"人多"要译成"别人大多"才通顺。

### ❌ 错误 4：虚词漏译
```
原文：逝者如斯夫，不舍昼夜。
错译：逝去的像这样，不分昼夜。
正译：逝去的事物就像这江水一样啊，不分昼夜[地流淌]。
```
"夫"是感叹语气词，"斯"特指眼前江水（上下文），都要传达。

### ❌ 错误 5：把典故"平译"掉
```
原文：三人行，必有我师焉。
错译：三个人在一起走，一定有我的老师。
正译：几个人同行，其中一定有可以作我老师的人。
```
"三"在古汉语中常作虚指（约数），不是实指 3 人。

## 特殊文类的翻译要点

### 诗/赋
- 尽量保留原文意象（"大江东去" 不译成 "大河向东流")
- 对偶句译文也尽量对仗
- 不必追求押韵（现代白话无法复原原韵）

### 奏疏/表
- 自谦谦辞（臣/草民/下官）保留或对应译
- 敬辞（陛下/陛下）保留

### 对话
- 保留语气词的情感（"矣" 有完成感/无奈感，"乎" 有疑问/感叹）

## 工具辅助

- 不确定某字古义？`search.py` 找典籍中其他用法
- 翻译完后校验？`cite.py --verify "你的原文片段"` 看这段是否在底本
- 翻译出来不对？`lookup.py 人名` 看人物档案是否匹配你理解的时代/身份
