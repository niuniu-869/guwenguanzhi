# 古今异义陷阱清单

> **强制**：凡解释古文词义时，先查此清单。字都认识但义不同的字是理解古文最大的坎。

## 一、最常被误读的古今异义

| 字/词 | 古义 | 今义 | 例句 |
|---|---|---|---|
| **妻子** | 妻 + 子女 | 配偶 | "率妻子邑人来此绝境"（桃花源记） |
| **丈夫** | 成年男子 | 配偶 | "生丈夫，二壶酒一犬"（勾践·越绝书） |
| **走** | 跑 | 走路 | "夸父与日逐走"（山海经） |
| **涕** | 眼泪 | 鼻涕 | "临表涕零"（出师表） |
| **去** | 离开 | 前往 | "西蜀之去南海，不知几千里也"（为学） |
| **行李** | 外交使节 | 旅行物品 | "行李之往来，共其乏困"（烛之武退秦师） |
| **交通** | 交错相通 | 运输系统 | "阡陌交通"（桃花源记） |
| **绝境** | 与世隔绝之地 | 无法脱身 | "来此绝境"（桃花源记） |
| **鲜美** | 鲜艳美丽 | 味道好 | "芳草鲜美"（桃花源记） |
| **风流** | 有才华 / 传统 | 多情 | "数风流人物"（沁园春） |
| **风骚** | 《诗经·国风》《离骚》 | 轻浮 | 同上 |
| **牺牲** | 祭祀的牲畜 | 捐躯 | "牺牲玉帛"（曹刿论战） |
| **烈士** | 有节操的人 | 战争捐躯者 | "烈士暮年，壮心不已"（龟虽寿） |
| **卑鄙** | 身份低微 | 道德败坏 | "先帝不以臣卑鄙"（出师表） |
| **可以** | 可以凭借 | 可能 | "忠之属也，可以一战"（曹刿） |
| **地方** | 土地方圆 | 区域 | "地方百里"（孟子·梁惠王） |
| **中国** | 中原 | 国家名 | "三年，宣王复会诸侯于东都，遂率以伐淮夷"（史记） |
| **中原** | 平原 / 战场中央 | 地理区 | "战于中原"（左传） |
| **黎明** | 光明前夜 | 清晨 | （少数文本） |
| **感激** | 感慨激奋 | 感谢 | "由是感激"（出师表） |
| **然后** | 这样之后 | 接着 | "然后知生于忧患"（孟子） |
| **其实** | 它的果实 / 它的实情 | 实际上 | "叶徒相似，其实味不同"（晏子春秋） |
| **形容** | 形体容貌 | 描述 | "形容枯槁"（屈原列传） |
| **指示** | 指出给看 | 命令 | "璧有瑕，请指示王"（廉颇蔺相如） |
| **以为** | 把...当作 | 认为 | "以为桂林、象郡"（过秦论） |
| **深度** | 水深的程度 | 深入程度 | 古无此词搭配，勿误用 |
| **独立** | 独自站立 | 不依附 | "赵军独立"（廉颇蔺相如） |
| **交代** | 交替、更替 | 吩咐 | "冬夏交代"（古文通用） |
| **因此** | 凭借这个 | 因果连词 | "因此屈己以待人"（《汉书》） |
| **从而** | 跟随并 | 连接副词 | "从而谢焉"（《礼记》） |
| **往往** | 到处 / 常常 | 经常 | "山水之间往往有焉"（各家） |
| **殷勤** | 诚恳恳切 | 热情招待 | "致殷勤之意"（赤壁） |
| **慷慨** | 感慨悲叹 | 大方 | "慷慨悲歌"（史记） |
| **博学** | 广泛学习 | 学问渊博 | "博学而笃志"（论语） |
| **假** | 借 | 假的 | "以是人多以书假余"（送东阳马生序） |

## 二、易错的多义字

### `之`
1. 代词：他/她/它（`为之奈何`=为此事怎么办）
2. 助词：的（`赤子之心`=赤子的心）
3. 动词：到、往（`吾欲之南海`=我想去南海）
4. 宾语前置标志（`何陋之有`=有何陋）
5. 主谓之间取消独立性（`孤之有孔明，犹鱼之有水也`）

### `其`
1. 代词：他/她/它/它们（`欲勿予，即患秦兵之来`）
2. 副词：大概/难道（`其可怪也欤`=难道不奇怪吗）
3. 指示代词：那（`于乱石间择其一二扣之`=选其中一两块）
4. 用在句首表示祈使/推测

### `以`
1. 介词：用/凭借（`以子之矛，攻子之盾`）
2. 连词：来（`以观其变`=来观察变化）
3. 通"已"：已经（古籍偶见）
4. 介词：因为（`以其求思之深而无不在也`=因为他钻研深入）

### `于`
1. 介词：在/到/从（`战于长勺`=在长勺作战）
2. 介词：对（`于我心有戚戚焉`=对我的心有所触动）
3. 介词：被（`受制于人`=被人控制）
4. 介词：比（`青出于蓝而胜于蓝`=比蓝更...）

### `而`
1. 并列：和/又（`黑质而白章`=黑底白花纹）
2. 顺承：然后/就（`人非生而知之者`）
3. 转折：却（`远而望之，皎若太阳升朝霞`）
4. 修饰：地（`默而识之`=默默地记住）
5. 假设：如果（`人而无信，不知其可也`）

## 三、词类活用（最易忽略）

古文中名词/形容词常"活用"作动词/状语等：

| 类型 | 例句 | 解读 |
|---|---|---|
| 名词作动词 | `沛公军霸上` | 军=驻军 |
| 名词作状语 | `斗折蛇行` | 斗=像北斗那样（曲折），蛇=像蛇那样（蜿蜒） |
| 形容词作名词 | `将军身披坚执锐` | 坚=坚硬的铠甲，锐=锋利的兵器 |
| 动词作名词 | `殚其地之出` | 出=产出 |
| 使动用法 | `项伯杀人，臣活之` | 活=使之活 |
| 意动用法 | `吾从而师之` | 师=以...为师 |
| 为动用法 | `等死，死国可乎` | 死=为国而死 |

## 四、易混文言句式

### 被动句
- `见 + 动词`：`信而见疑`=诚信却被怀疑
- `于 + 施事者`：`不拘于时`=不被时俗拘束
- `为 + 所 + 动词`：`为天下笑`=被天下人嘲笑

### 判断句
- `...者...也`：`廉颇者，赵之良将也`=廉颇是赵国名将
- `...为...`：`子为谁` =你是谁
- `乃/则/即`：`此则岳阳楼之大观也`=这就是岳阳楼雄伟景象

### 宾语前置
- 疑问代词作宾语：`大王来何操`=大王来带了什么
- 否定句代词宾语：`古之人不余欺也`=古人不欺骗我
- `之`作标志：`何陋之有`=有什么简陋
- `是`作标志：`唯利是图`=只追求利益

## 五、最易幻觉的伪古文

Agent 常"造"出来的假古文形式：

❌ `古人云：做人要诚信` — 无出处的伪古
❌ `史载：赤壁之战死者无数` — 史书不这么说
❌ `孔子曰：吾有三宝` — "我有三宝"是老子不是孔子
❌ `诸葛亮：鞠躬尽瘁死而后已` — 原文是"鞠躬尽力"（出师表），后世讹为"尽瘁"
❌ `范仲淹：天下兴亡匹夫有责` — 这是顾炎武，不是范仲淹
