## 分期

### 1. 秦（前221—前207）
核心矛盾：郡县制 vs 六国遗民 + 皇权集中 vs 帝位传承。关键卷：`shiji/本纪/006`（始皇）、`shiji/列传/008`（商君溯源）、`shiji/列传/027`（李斯）、`shiji/列传/028`（蒙恬）。

### 2. 楚汉之争（前206—前202）
核心矛盾：贵族政治 vs 军功集团。关键卷：`shiji/本纪/007`（项羽）、`shiji/本纪/008`（高祖）、`shiji/世家/025`（张良）、`shiji/世家/023`（萧何）、`shiji/世家/026`（陈平）、`shiji/列传/032`（淮阴侯韩信）、`shiji/列传/031`（黥布）。

### 3. 西汉前期（前202—前141）
黄老无为 + 削藩。关键卷：`shiji/本纪/009`（吕后）、`shiji/本纪/010`（文帝）、`shiji/本纪/011`（景帝）、`shiji/列传/041`（袁盎晁错）、`shiji/列传/046`（吴王濞）、`shiji/列传/042`（张释之冯唐）。

### 4. 武帝盛世与转折（前141—前87）
对外扩张 + 罢黜百家 + 财政危机。关键卷：`hanshu/帝纪/006`、`shiji/列传/049-051`（李广/匈奴/卫青霍去病）、`shiji/列传/058`（淮南衡山）、`shiji/列传/061`（儒林）、`shiji/列传/063`（大宛）、`shiji/书/008`（平准书）、`hanshu/志/002`（礼乐志）。

### 5. 昭宣中兴到西汉末（前87—公元8）
霍光辅政 + 宣帝综核名实 + 外戚崛起。关键卷：`hanshu/帝纪/007`（昭帝）、`hanshu/帝纪/008`（宣帝）、`hanshu/帝纪/009-012`（元成哀平）。

### 6. 王莽与东汉（8—220）
王莽改制翻车 → 光武中兴 → 外戚宦官 → 党锢 → 黄巾 → 军阀割据。关键卷：`houhanshu/帝纪/001`（光武）、`sanguozhi/魏志/001-006`（曹操崛起 / 董卓乱政）。

## 制度与地理速查

- **官制**：三公九卿 → 尚书台权力上升。关键卷：`hanshu/志/010`（艺文）附百官源流；东汉百官志见 `houhanshu/志/024-028`
- **律法**：秦律苛酷、汉承秦制、文景约法。`hanshu/志/003`（刑法志）
- **地理**：关中 / 关东（函谷关以东）/ 巴蜀 / 岭南 / 河西四郡 / 西域都护府
- **经济**：盐铁官营、均输平准、算缗告缗。`shiji/书/008`（平准书）；东汉见 `houhanshu/志/019-023`（郡国志）
- **军事**：北逐匈奴、南平百越、通西域

## 读这段史的坑

- 《史记》对汉武帝有隐讳之处（司马迁受腐刑），须与《汉书》对照
- 《后汉书》成书于刘宋，对东汉人物评价带后见之明
- 王莽一朝在《汉书》中被定性为"篡"，读时需剥离正统叙事
- 三国志魏志卷 1 "武帝纪"即曹操传，此时东汉尚未亡，名义仍是汉臣
- metadata 中 `houhanshu` 仅 31 卷（全书 120），列传部分须查原文或等待补全
