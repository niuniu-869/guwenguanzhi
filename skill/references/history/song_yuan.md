## 分期

### 1. 五代十国（907—960）
武人政治 + 契丹崛起。关键卷：`jiuwudaishi` / `xinwudaishi` 本纪；李克用/李存勖（后唐）、石敬瑭（后晋）、郭威/柴荣（后周）。

### 2. 北宋（960—1127）
重文抑武 + 冗官冗兵冗费。关键卷：`songshi/本纪/001-023`；太祖杯酒释兵权、澶渊之盟、庆历新政、熙宁变法、元祐党争、徽钦被掳。

### 3. 南宋（1127—1279）
南渡半壁 + 和战之争 + 最终亡于蒙古。关键卷：`songshi/本纪/024-047`；岳飞、秦桧、韩侂胄、史弥远、贾似道、文天祥、陆秀夫。

### 4. 辽（907—1125）
契丹建国 + 南北面官制 + 澶渊后百年承平 + 亡于金。关键卷：`liaoshi/本纪/001-030`；耶律阿保机、耶律德光、承天太后、圣宗、天祚帝。

### 5. 金（1115—1234）
女真崛起 + 速灭辽宋 + 迁都中都 + 被蒙古压崩。关键卷：`jinshi/本纪/001-019`；阿骨打、完颜宗翰、完颜亮（海陵王）、世宗、章宗、宣宗、哀宗。

### 6. 元（1206—1368）
蒙古帝国东部继承者。关键卷：`yuanshi/本纪/001-047`；成吉思汗、窝阔台、蒙哥、忽必烈、伯颜、脱脱、元顺帝。

## 制度与地理速查

- **宋**：二府三司（中书、枢密、三司）+ 科举扩招 + 路-府州军-县
- **辽**：南北面官（北面治契丹、南面治汉人）+ 五京制（上、中、东、南、西）
- **金**：猛安谋克（军民合一）+ 仿宋三省
- **元**：行省制创立（中书省 + 岭北、辽阳、河南、陕西、四川、甘肃、云南、江浙、江西、湖广、征东）；四等人（蒙古、色目、汉人、南人）
- **经济**：宋代商业/城市革命、交子（世界最早纸币）、漕运；金银铸钱 + 元末宝钞恶性通胀
- **思想**：北宋五子（周、张、二程）→ 南宋朱熹理学集成 → 陆九渊心学萌芽；元代以朱注为科举标准

## 读这段史的坑

- **辽金宋元四史并行**：同一事件在各国史书中立场相反（如澶渊之盟、靖康之变、崖山之战）。读宋史要补读辽/金/元对应本纪。
- **脱脱总裁**：辽/金/宋三史均由脱脱主修，体例一致但仓促编成，史源错漏较多；宋代笔记（《续资治通鉴长编》等）比正史更可信
- **南宋偏安的史料偏见**：《宋史》对秦桧定性为奸臣，岳飞为神，但南宋官方档案也有加工
- **元朝记载散乱**：《元史》一年修成，卷数虽多但内容重复冗杂；须合参《元朝秘史》《蒙鞑备录》等外史
- **年号与庙号对应**：宋帝庙号"太祖/太宗/真宗"等与年号（建隆、太平兴国、大中祥符）须互查
