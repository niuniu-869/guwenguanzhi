## 分期

### 1. 明前期（1368—1449）
集权巅峰 + 海外伸张 + 军事守势收缩。关键卷：`mingshi/本纪/001-012`、列传 125（朱元璋）、列传 137（徐达）、列传 303（郑和）。核心变化：废丞相、设内阁、迁都北京、营建紫禁城。

### 2. 明中期（1449—1572）
内阁党争 + 宦官专权 + 北虏南倭。关键卷：`mingshi/本纪/010-019`；王守仁（平宁王之乱）、严嵩/徐阶/高拱、戚继光/俞大猷（抗倭）、张璁（大礼议）、海瑞。

### 3. 晚明（1572—1644）
张居正改革 → 万历怠政 → 党争激化 → 明清战争 → 流寇入京。关键卷：`mingshi/本纪/019-024`；张居正、魏忠贤、东林党、袁崇焕、熊廷弼、孙承宗、洪承畴、李自成、崇祯、史可法。

### 4. 清前中期（1616—1796）
满洲崛起 + 三藩削平 + 康乾盛世 + 文字狱与闭关。关键卷：`qingshigao/本纪/001-015`；努尔哈赤、皇太极、多尔衮、顺治、康熙、雍正、乾隆、鳌拜、吴三桂、张廷玉、鄂尔泰、傅恒、和珅。

### 5. 嘉道时期（1796—1850）
白莲教 + 鸦片战争 + 内忧外患并起。关键卷：`qingshigao/本纪/016-018`；林则徐、穆彰阿、琦善。

### 6. 晚清（1850—1912）
太平天国 + 洋务运动 + 甲午惨败 + 戊戌变法 + 庚子事变 + 清末新政 + 辛亥革命。关键卷：`qingshigao/本纪/019-025`；曾国藩、李鸿章、左宗棠、张之洞、慈禧太后、奕䜣、恭亲王、光绪、康有为、梁启超、袁世凯、孙中山（清末新政史料）。

## 制度与地理速查

- **明**：废丞相 → 内阁大学士"票拟"→ 司礼监"批红"制衡；卫所制 + 募兵；一条鞭法（张居正）
- **清**：军机处（雍正）+ 议政王大臣会议逐渐虚化；八旗 + 绿营 + 后期湘淮勇营；摊丁入亩（雍正）；理藩院管边疆
- **地理**：明两京（南京、北京）、九边（辽东、蓟州、宣府、大同、山西、延绥、宁夏、固原、甘肃）；清满、蒙、回、藏四部 + 内地十八省 + 后来东北三省
- **思想**：阳明心学（王守仁）→ 泰州学派 → 乾嘉考据学（顾炎武、黄宗羲、王夫之、戴震、钱大昕）→ 晚清今文经学（龚自珍、魏源、康有为）

## 读这段史的坑

- **明史为清修**：对建文帝结局、南明诸政权、郑成功定位等持清廷立场
- **清史稿未定本**：1927 仓促出版后清廷旧臣立场明显（如对太平天国、义和团的用词）、有未删的"伪""逆"贬词
- **民族问题**：明史对蒙古"北虏"、清史稿对汉人反清运动的术语需批判阅读
- **晚清条约与战争**：列强视角缺失，须合参《筹办夷务始末》《清实录》光绪朝、外交档案
- **人物重名**：明清帝王多只称庙号/年号（洪武、永乐、嘉靖、万历、崇祯、康熙、乾隆、光绪），lookup 时须同时检索年号和庙号
- **女主评价**：孝庄、慈禧在清史稿中的评价反差对照阅读
