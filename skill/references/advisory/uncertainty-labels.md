# 三标签规范：【史实】/【演绎】/【推断·建议】

> **强制**：凡涉及"以史为鉴/历史告诉我们/古人云"类回答，每段必须带标签；未带标签的"历史建议"视为幻觉风险。

## 为什么要有标签

Agent 给出历史类比时，用户无法区分这是"史书原载的事实"还是"你自己的类比演绎"，更无法区分"你在建议"还是"你在陈述"。三标签解决这个断层。

## 三类标签的界线

| 标签 | 适用范围 | 必须满足 |
|---|---|---|
| **【史实】** | 人物/事件/年代/原文引用 | 能通过 `cite.py` 或 `search.py` 校验到二十四史、诸子百家、权威注疏等底本 |
| **【演绎】** | 从史实推出的**模式**、**教训**、**现代对应** | 必须先陈述史实（带 URN），演绎内容是对该史实的合理推论 |
| **【推断·建议】** | 对用户当前情境的具体操作建议 | 不得冠以"古人言""史载""历代皆然"等措辞；必须标明"这是基于上述史实的推断，非历史本身" |

## 标签使用模板

```
【史实】《史记·留侯世家第二十五》载：汉六年封侯时，诸将未封者相聚沙中谋反。
张良建议刘邦"先封雍齿，以安诸将"，刘邦"乃急封雍齿为什方侯"。
（出处: shiji/世家/25/008；cite.py 已校验）

【演绎】这是一个"用最刺眼的反例示诚意"的模式：让群体中最不满的人先受益，
其他人会自动相信制度是公平的。

【推断·建议】你在组织变革后稳定人心，可以优先照顾那个"最有理由离开的人"
——这不是古人教你的，是从萧何/张良这类案例中抽出的模式，现代场景未必完全适用。
```

## 反模式（禁止）

❌ "历史告诉我们，凡变革必慢推" — 把演绎伪装成史实  
❌ "古人云，用人不疑" — 虚构古文出处  
❌ "根据《资治通鉴》，创业合伙人应 XYZ" — 把现代建议冠以典籍名义  
❌ "司马光说现代企业应该..." — 把人物拽到现代  

## 检查清单

写完回答前自检：
- [ ] 每处历史引用是否走过 `cite.py --verify`？
- [ ] 演绎的前提史实是否清晰陈述？
- [ ] 给用户的具体操作建议是否标了【推断·建议】？
- [ ] 是否存在"古人言"但没列出具体人/书/卷？→ 有 = 幻觉

## 三标签 + cite.py 联动

每个【史实】段**后置** URN 供用户复核：
```
【史实】刘邦入关后"与父老约法三章"（shiji/本纪/008/003）
```

如果 URN 未命中（cite.py 返回找不到），则该段**必须降级为【推断】或删除**。
