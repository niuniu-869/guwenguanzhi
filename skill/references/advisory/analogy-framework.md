# 类比思维框架：现代情境 → 历史先例

> **原则**：历史不会重复，但**模式**会。类比的价值在抽象"可迁移的模式"，不在细节对应。

## 什么是好的历史类比

**好类比**：情境的**结构相似**（决策者角色/冲突类型/信息条件），而非表面事件相似。

- ✅ "创业合伙人理念冲突" ↔ "楚汉相争"：两个目标接近但路径分歧的领导者必须选边，都不能共存
- ❌ "公司 IPO 被拒" ↔ "宋江招安被毒酒"：事件名相似但结构无关，属于浅层联想

## 类比的 4 步法

### Step 1：抽取现代情境的"结构骨架"

先问三个问题：
1. **决策者的角色** 是什么？（创始人 / 继承人 / 重臣 / 外部顾问）
2. **核心冲突** 是什么？（资源分配 / 路线分歧 / 信任危机 / 时间压力）
3. **信息条件** 是什么？（完全信息 / 部分可见 / 对手隐藏）

### Step 2：`analogy.py` 查库

```bash
python skill/scripts/analogy.py "你的情境描述"
```

advisory_fts 会返回匹配的 modern_relevance 候选，每条带出处卷。

### Step 3：逐条评估结构匹配度

不是 LLM 返回的第一条就是答案。自问：
- 这条候选的**决策者角色**和我的情境一致吗？
- **冲突类型**是同一类还是表面词重合？
- **信息条件**（古代消息慢、现代实时）差异会否让"对应教训"失效？

**宁可少给一条高质量类比，不给三条凑数的。**

### Step 4：抽出"模式"再落到建议

类比的输出不是"X 对应 Y"，而是：
```
【史实】原事件（URN 可查）
【演绎】从该事件抽出的模式（20 字以内表达）
【推断·建议】该模式迁移到用户情境的具体动作（必须承认"未必完全适用"）
```

## 类比 **不能** 做的事

### ❌ 把古代人丢到现代场景

"刘邦会怎么做？" → 这是 agent 在扮演，不是史实。刘邦面对的是冷兵器时代的人力组织，不能直接告诉他怎么做 B 轮融资。

### ❌ 用单一案例作"历代皆然"

找到一条类比后说"这就是历史规律"——规律要多个独立案例才能提炼。一条只能说"历史上有过类似情境"。

### ❌ 用胜利者案例作万能答案

史书偏载胜者，容易产生"谁这样做谁就成功"的错觉。
反例：赵括的"纸上谈兵"只因输了被批，韩信背水一战同样违反兵法却被颂扬。
→ 类比时**同时找正反两个先例**。

### ❌ 现代问题直接套古代解

古人"杯酒释兵权"的温和化解基于**绝对权力 + 个人恩义**两个条件。现代公司 CEO 让联合创始人股权回收，不能直接效仿；但可以借鉴"给足退路比强硬对抗便宜"这一**模式**。

## 标准类比输出模板

```
用户情境："合伙人理念不合想分家"

【史实】《史记·魏公子列传》等载：战国四公子之首信陵君窃符救赵后，
  避仇居赵十余年，与其兄魏安釐王长期疏远。兄弟之间因权力/声望/
  路线分歧彼此警惕，即使血亲也难以共存。(shiji/列传/017)

【演绎】当两个核心决策者目标分化到"谁也不能接受另一方主导"时，
  物理分离常比勉强协作更稳定——但必须在**公开承认分歧**后友好分开，
  而非"貌合神离"。

【推断·建议】若你们仍有交集业务，建议：
  ① 明确各自业务边界（参考战国"分地而治"）
  ② 保留形式上的联系（公子归魏后安釐王仍以礼相待）
  ③ 设计"互不介入"的边界条款（现代属于法律层面）
  
注意：信陵君/安釐王的血亲关系提供缓冲，合伙人若无这层，风险更高。
```

## 何时不给类比

用户问题明显属于以下场景，**应拒绝类比**并说明：

- 法律合规（不要用历史案例推翻现行法律）
- 现代金融/技术专业问题（算法、融资工具、合规细节）
- 精神健康 / 重大生活决策（职业/婚姻）—— 历史案例时代差异太大
- 高度个性化纠纷（家庭/朋友具体矛盾）—— 应建议面对面沟通
