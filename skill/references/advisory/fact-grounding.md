# 史实核查流程

> **原则**：不确定的引用，要么查证要么删除。**"大概记得"等于"编造"**。

## 何时触发核查

任何涉及以下内容的回答，都要在写入前走核查流程：

- 具体年代（"公元前 207 年""武德九年"）
- 具体原文片段（"吾当以此报之""大丈夫当如是也"）
- 具体人物言行（"诸葛亮说..."、"李世民问..."）
- 具体事件细节（"鸿门宴上项庄舞剑""玄武门之变 626 年"）
- 典籍卷目定位（"《史记·高祖本纪》""《资治通鉴·唐纪》"）

## 标准核查步骤

### Step 1：先问"这是我真记得的，还是在合理化？"

如果回答是"应该是这样""大概吧"—— **直接进 Step 2**，不要写。

### Step 2：用 `cite.py --verify` 校验片段

```bash
python skill/scripts/cite.py --verify "原文片段"
```

- ✅ 命中：拿到 URN，引用时标注
- ⛔ 未命中：**不要写这句**，改用概述或省略

### Step 3：用 `search.py` 查模糊记忆

不记得原文，只记得大意？先用 `search.py` 找：

```bash
python skill/scripts/search.py "关键词" --limit 5
```

拿到候选后，再用 `cite.py shiji/世家/25` 取原文看是否匹配。

### Step 4：人物跨卷用 `lookup.py`

不确定某人事迹在哪本书？

```bash
python skill/scripts/lookup.py 人名
# 或别名反查
python skill/scripts/lookup.py 留侯
```

返回 figure_cards 合并视图：该人出现在哪些卷 + 每卷角色摘要。

### Step 5：年代用 `timeline.py`

"安史之乱前后有什么大事？"

```bash
python skill/scripts/timeline.py --from 755 --to 763
```

## 核查失败后的回退策略

按**降级顺序**：

1. **能命中但不确定精度** → 仍写，但标【史实·摘要】而非【史实·原文】
2. **事件本身可信、具体细节不确定** → 写模糊表述："史载秦末有..."  而不是 "公元前 209 年 X 月刘邦..."
3. **完全无法核实** → 明示【推断】或**直接不答**。给出"我不确定这一点，建议查..."

## 常见幻觉模式（警惕）

| 模式 | 症状 | 处理 |
|---|---|---|
| 名言误植 | 把别人的话安在名人头上（如"圣人不凝滞于物"来自《楚辞》非《论语》）| 走 cite.py，查不到就删 |
| 朝代穿越 | 汉人引唐诗、唐人用宋词 | 用 timeline 定位年代 |
| 典故重写 | 鸿门宴细节添油加醋 | 取 cite.py 原文，只写原文有的 |
| 互文错配 | "三国志说刘备..."（应是诸葛亮/陈寿评价）| lookup 人物定位传在哪卷 |
| 演义当史 | 把《三国演义》当《三国志》 | 仅二十四史/诸子原文可信 |
| 百度式伪引 | "据史书记载" 不说哪本 | 必须具体到书·卷·段 |

## 核查成本与收益

每次核查大约 1-2 次脚本调用（< 2 秒），对比幻觉引用带来的**用户信任崩塌**，绝对划算。

**规则**：答复中每出现一个具体引用/年代/原文，就要有一次核查（或已在前文核查过的复用）。
