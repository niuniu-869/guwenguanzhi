## 任务

为下列古籍单卷生成结构化元数据。

**典籍**：{book_name}
**卷号**：第 {juan} 卷（语义编号：{sub_type}第{sub_index}）
**卷名**：{juan_name}
**作者**：{author}
**朝代**：{dynasty}

**原文**（可能为节选；以本段内容为准，不要编造未出现的人物或事件）：
```
{text}
```

  "key_events": [
    {

## 字段细则

- **key_figures**：3-8 人，按本卷重要性排序；aliases 包含字、号、谥号、封号、史书别称（如「张良」aliases 含「子房」「留侯」「文成侯」）
- **key_events**：3-10 件，按时间顺序；不要罗列所有事件，挑塑造本卷主线的关键节点
- **cross_refs**：尽量给出 2-5 条；体例对照（同一人物在《汉书》另有传）、思想源流（《孟子》引用《诗经》）、事件互证（《左传》《国语》互参）都可
- **modern_relevance**：仅当本卷确有可类比的现代情境时给出；空数组优于强行附会

只输出 JSON，不要任何前后说明。
